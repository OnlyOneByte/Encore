# docs/research/

Findings that inform a decision not yet taken — surveys of how other systems solve a problem,
measurements, and the reasoning they support.

Distinct from a tracked GitHub issue, which describes what we are **going to build** (with acceptance
criteria). A file here has no commit plan and nothing scheduled against it. When a research note turns
into committed work, the issue that supersedes it links back here rather than restating it.

| File | Question it answers |
|---|---|
| `scoring.md` | If scoring is rebuilt, what should it measure and what blocks it |
