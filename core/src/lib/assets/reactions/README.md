# Reaction glyphs

`clap.svg`, `fire.svg`, `laugh.svg` and `heart.svg` are Noto Emoji artwork by Google Inc.
(https://github.com/googlefonts/noto-emoji), used unmodified under the Apache License 2.0
(https://github.com/googlefonts/noto-emoji/blob/main/svg/LICENSE). Extracted from the
`@iconify-json/noto` package.

They are bundled rather than typed as emoji so a TV with no colour-emoji font (a bare Linux
kiosk) still draws them, and so every phone and TV draws the same four pictures.
