# Reaction glyphs

`clap.svg`, `fire.svg`, `laugh.svg` and `heart.svg` are Noto Emoji artwork, Copyright Google LLC
(https://github.com/googlefonts/noto-emoji), used unmodified under the Apache License, Version 2.0, a
copy of which is in `LICENSE` beside them. The Noto Emoji README puts "tools and most image resources"
under Apache 2.0 (the fonts are under the SIL OFL, which does not apply here). Extracted from the
`@iconify-json/noto` package, which redistributes the same SVGs under Apache-2.0.

They are bundled rather than typed as emoji so a TV with no colour-emoji font (a bare Linux kiosk)
still draws them, and so every phone and TV draws the same four pictures.
